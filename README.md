# Dockerfile Templates for Wiz C2C PoC

This repository contains Dockerfile templates that are referenced by other repositories in the Wiz Code-to-Cloud (C2C) Proof of Concept.

## Purpose

- Store centralized Dockerfile templates for consistent container builds
- Enable template reuse across multiple projects
- Provide standardized base configurations for C2C scanning and analysis

## Usage

Reference templates from this repository in your projects by using the raw GitHub URLs or by cloning this repository as a submodule.

